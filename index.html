Privacy Policy — ContentHub Lite

Last updated: 28 September 2026

ContentHub Lite is a personal, single-user content automation tool built and operated by Antônio Carlos da Rocha Jr. (linkedin.com/in/acrochajr). It drafts and schedules posts about software engineering and AI, and publishes them to the author's own social accounts. It is not a product offered to third parties, has no other users, and has no sign-up.

What the application accesses

When the author authorizes the application through LinkedIn, it receives, via the LinkedIn API:

  • Basic profile identifiers (member ID and name), through Sign In with LinkedIn using OpenID Connect, used solely to address posts to the correct account.
  • Permission to publish on the author's behalf, through w_member_social.

The application does not read the author's connections, feed, messages, or the profiles of any other LinkedIn member.

What is stored, and where

The access token and the member identifier are stored in a local SQLite database file, on hardware controlled by the author. Nothing is stored on a hosted server, and no database is exposed to the internet.

What is not done

  • No data is sold, rented, shared, or transferred to third parties.
  • No analytics, advertising, tracking, or profiling.
  • No data is collected about any person other than the author.
  • No cookies are set — the application has no public web interface.

Retention and revocation

Credentials are kept only while the integration is in use, and are deleted when it is retired. Authorization can be revoked at any time from LinkedIn, under Settings & Privacy → Data privacy → Other applications → Permitted services. Revoking access immediately stops the application from publishing.

Third-party processors

Post content is generated with the assistance of a large language model API. Only the text intended for publication is sent for processing; no LinkedIn credentials, tokens, or member data are included in those requests.

Changes

If this policy changes, the revision date above is updated.
